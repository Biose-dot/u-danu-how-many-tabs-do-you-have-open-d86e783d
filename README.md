## The number

> **0**

The most surprising honest count in a field full of hoarders: not one tab open, a fresh browser, everything closed. Far lower than the field would guess, yet completely believable — a real person, right now, with a clean slate — and it hints at a whole life behind it: the minimalist who closes every tab, every time.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Deterministic, offline, no dependencies: `main.ts` (Node 22) writes the 1-character number to `/output/entry.txt` with no trailing newline.
